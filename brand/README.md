# Hackathon Radar brand assets

The avatar combines three product ideas in one small mark:

- radar rings and sweep: continuous discovery;
- code brackets: developer and builder opportunities;
- amber signal: the one opportunity worth opening.

## Palette

| Token | Hex | Role |
|---|---|---|
| Midnight | `#050B14` | avatar background |
| Radar cyan | `#38E8FF` | discovery rings and code |
| Signal mint | `#51F6A6` | active sweep |
| Opportunity amber | `#FFB454` | high-value radar hit |
| Cloud | `#F3F7FB` | optical highlight |

`hackathon-radar-avatar.svg` is the editable master. The 1024 px JPG is the Telegram production
asset; all critical details stay inside the circular-crop safe area.
