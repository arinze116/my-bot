# Source and deployment research — 2026-11-16

## Executive summary

The PRD's product flow remains viable, but several 2025-era technical assumptions are stale. Devpost, DoraHacks, MLH, and HackerEarth all expose usable current data contracts, although not at the listed endpoints. Lablab now redirects to Starfield Labs and currently shows no events. The former Grants Stack host no longer resolves, so Gitcoin coverage must use its current public campaigns surface and can only emit entries explicitly labelled as hackathons or bounties.

## Findings

- **Verified:** Devpost's Cloudflare layer blocks `/hackathons` and `/hackathons.rss` from this host, while `https://devpost.com/api/hackathons?status[]=open&order_by=recently-added` returns JSON listing data.
- **Verified:** DoraHacks' old `/api/hackathon/` contract returns 404. Its current production bundle calls `https://dorahacks.io/api/v1/hub/hackathons`, which returned paginated JSON on 2026-11-16.
- **Verified:** Devfolio embeds `open_hackathons` JSON in `__NEXT_DATA__` at `https://devfolio.co/hackathons`.
- **Verified:** MLH embeds `upcomingEvents` JSON in a `data-page="app"` script at `https://www.mlh.com/seasons/<year>/events`.
- **Verified:** HackerEarth's listed v3 events endpoint redirects to login. Its current site calls `https://www.hackerearth.com/api/community/challenges/compete/`, which returned hackathon records.
- **Verified:** `https://lablab.ai/event` redirects to `https://starfieldlabs.ai/events`; the latter said "No events yet" during research.
- **Verified:** `grants-stack.gitcoin.co` and the old indexer host did not resolve. `https://gitcoin.co/campaigns` is reachable, but it is a campaign catalogue rather than a hackathon API.
- **Verified:** X recent search is `GET /2/tweets/search/recent`, returns up to 100 results per request, and accepts app-only bearer authentication. Access pricing is account-specific; the PRD's claim of a universally free Basic tier is not verified.
- **Verified:** Telegram `sendMessage` accepts 1–4,096 characters after entity parsing.
- **Verified:** Railway currently documents a $0 plan with $1 monthly usage credit and up to 0.5 GB volume storage. This is a usage allowance, not proof that every always-on worker remains free.
- **Strongly supported:** A small sleeping Python worker may fit Railway's credit, but actual memory/CPU usage must be measured after deployment.
- **Unknown:** provider SLAs and advance notice for these public/undocumented listing contracts.
